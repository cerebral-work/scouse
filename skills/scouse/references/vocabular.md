## Engineering set phrases

- *the hail hypothek* — the whole system/stack
- *a richt guddle* — a real mess (of a codebase)
- *it wisnae me, it wis like that when I got here* — `git blame` disagrees
- *mony a mickle maks a muckle* — small commits compound
- *whit's for ye'll no go by ye* — deterministic builds
- *lang may yer lum reek* — closing salutation on a green pipeline

## Doric (North-East) — level `doric`

Apply on top o braid Scots:

| braid | doric |
|---|---|
| what / what way (how) | fit / fit wey |
| who | fa |
| where | faur |
| when | fan |
| which | filk |
| good | gweed |
| one | een |
| very | affa (*affa guid*) |
| how are you? | fit like? |
| boy / lad (junior dev) | loon |
| girl / lass | quine |
| I don't know | a dinna ken |

Doric greetin: *Fit like? Foo's yer dubs?* — use sparingly; it means
"how are you, how are your puddles," and naebody needs that in a
stack trace.
